# 原版与翻译实验版开发流程

> 2026-10-05。三条版本线已推送，默认分支切换用户选择暂缓；保护规则、Release 与构建开关仍待定。

## 分支和工作区

| 分支 | 职责 | 本地工作区 |
|---|---|---|
| `main` | 当前 V1.3 减翻译的稳定原版 | 从 `develop` 接收已验收变更 |
| `develop` | 无翻译原版日常集成 | `KazariPlay_main/` |
| `feature/hook-translation` | Hook/AI/字幕实验产品线 | `KazariPlay_V1.0/` |

实验源码完整保存于 `df48607`，此分支仅增加身份和流程文档，原有翻译前后端、Textractor、截图 Overlay 和本地生成物保留。原版不退回历史版本，公共缺陷也未因此自动修复。

## 同步规则

1. 原版功能/修复从 `develop` 切短期工作分支，验收后合入 `develop`，稳定后合入 `main`。
2. 翻译专属问题在实验分支处理，公共修复尽量单独提交，经审查后选择性 cherry-pick。
3. 不将实验分支整体合入 `main/develop`，也不将原版翻译移除提交合入实验分支；否则会重新引入翻译或删除实验实现。
4. 不对已共享的历史反复 rebase，不覆盖用户现有改动。
5. 每个 worktree 单独构建前端和 Overlay，不能混用 `js/`、`overlay/bin/bin32` 和 DLL/LIB。

## 数据和验证

原版保留旧数据库 Hook/翻译字段及配置扩展数据，但没有对应 UI、API、注入或 AI 执行链。原版常规写入不覆盖旧翻译列，恢复默认也保留旧翻译配置。两版不要同时写真实用户库；测试使用副本和隔离配置，截图不自动搬迁。

实验工作区旧截图、DLL、EXE、OBJ 和配置均保留。本轮实验源码不修复审查待办，普通离线测试必须隔离本机配置，避免打印 API Key；不得为回归调用付费 API。

实验前端继续使用原来的 17 个运行模块和翻译/字幕入口；实验测试 `tests/smoke_translation.py` 仍有 CSS 检查失配和 FakeOverlay 接口过时的问题，尚未全绿。真实 Hook、翻译服务和字幕稳定性需后续专门验证。

原版在独立工作区完成前端检查/构建、Python 语法与普通回归、旧数据兼容检查，并成功编译 x64/x86 截图 Overlay。原版 GUI 与截图 toast 已完成隔离实机冒烟。

## 远端待办

`main`、`develop` 和 `feature/hook-translation` 已推送，本地分别跟踪同名远端分支。GitHub 默认分支仍为 `master`：本机 `gh` 未登录，设置 API 操作被认证阻塞，用户明确选择暂缓切换。

旧 `master` 保留，不自动删除；默认分支调整前，访问 GitHub 首页仍看到旧版，应主动选择所需版本分支。后续完成 GitHub CLI 授权后切换默认分支，再单独决定旧分支处置。保护规则、构建开关和正式发布仍待定，本轮未操作。
