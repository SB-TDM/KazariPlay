# KazariPlay 主页设计稿

> 状态：**v0.1 设计稿（2026-10-11），待评审，未实施**。
> 范围：新增「主页」视图并作为默认视图；不改其它窗口、不改后端契约、不改数据库。
> 依据：所有取舍均经 2026-10-11 两轮问答确认，逐条记录见 §11。

## 2. 定位与入口

- 主页 = **聚合仪表盘 + 轻个人化（静态）**：按时段问候、头像占位、统计；不做昵称、不做头像上传、不做账号。
- 入口：**侧栏首项「主页」（house 图标）；作为默认视图**。
- 「全部作品」换新素材（用户提供；20px、`currentColor`，与现有侧栏图标同规格）；**原「个人」占位按钮保留现状**（暂未开放，不删除）。
- 主页**不使用副标题栏**（无视图名/搜索/批量/排序）；「收藏夹」开关按既有规则仍只在「全部作品」视图出现。
- **右下 FAB（刷新/手动添加）保留**，行为与其它视图一致。

## 3. 页面结构（自顶向下）

```
┌ 侧栏 ─┐┌ 主区（主页视图）────────────────────────────┐
│ 主页  ││ ① 头部：头像 + 问候语（+ 日期）                │
│ 全部  ││ ② 继续游玩：最近游玩的 6 款卡片               │
│ 最爱  ││ ③ 统计：总数 / 收藏数 / 总时长 / 最近一次游玩  │
│ ...   ││ ④ 收藏夹：前 8 个分组/分类 chips             │
│ 个人  ││                                     [FAB]    │
│ 主题  ││                                          │
│ 设置  ││                                          │
└──────┘└──────────────────────────────────────────┘
空库时：②④ 隐藏，页面中部显示扫描引导块。
```

## 4. 区块规格

### 4.1 头部
- 头像：圆角方块，复用 `person-circle` 图形 + 现有粉色渐变底；**装饰元素**（`aria-hidden`，不可聚焦）。
- 主行：按时段问候——`早上好 / 下午好 / 晚上好`（本地时间）。
- 次行（可选，评审定）：日期小字，如「10 月 11 日 周六」。
- 不显示昵称、不提供编辑入口。

### 4.2 继续游玩
- 标题：`继续游玩`。
- 数据：`App.data.games` 中 `last_played` 非空者，按 `last_played` 倒序（与「最近游玩」排序口径一致），取 **6 款**。
- 卡片：**完全复用现有卡片组件与交互**——封面懒加载/渐变兜底、运行中角标、左键详情、右键菜单（启动/目录/收藏夹/编辑/匹配/移除）、Tab/Enter 键盘路径。
- 数量自适应：桌面最多 6，窄窗按可视宽度自然减少（一行放下为准），不出现横向滚动。
- **跟随用户封面档位**（small/medium/large，与列表一致）。
- 无游玩记录时：**整块隐藏**。
- 首版**不加**「一键启动」按钮；不设「查看全部」链接（如需要另议）。

### 4.3 统计（4 项）
| 项 | 计算 | 交互 |
|---|---|---|
| 作品总数 | `games.length` | 点击 → 「全部作品」视图 |
| 收藏数 | `fav` 计数 | 点击 → 「我的最爱」视图 |
| 总游玩时长 | `sum(play_time)`（分钟）前端格式化 | 只读 |
| 最近一次游玩 | `max(last_played)` 对应游戏的 `last_text`（相对时间） | 只读 |

- 总时长格式与后端 `format_play_time` 同口径：`<60 分钟`按分钟；`≥60` 显示「X 小时 Y 分钟」（Y 为 0 时省略）；总值为 0 显示「0 分钟」。
- 可点击项用按钮语义并附 `aria-label`（如「共 35 部作品，查看全部作品」）。
- 库为空时显示 `0 / 0 / 0 分钟 / 无`。

### 4.4 收藏夹快捷
- 标题：`收藏夹`。
- 内容：按收藏夹树顺序平铺「分组 + 分类」chips，**取前 8 个**（名称超长省略号）；无收藏夹时整块隐藏。
- 点击 chip：走与抽屉选择相同的 `selectCollection` 路径——切到该收藏夹筛选视图并同步高亮/数量。
- **不加**「打开收藏夹」按钮（完整浏览仍去「全部作品」用抽屉）。

### 4.5 空库引导
- 0 作品时：头部与统计照常（0 值），继续游玩/收藏夹隐藏；页面中部显示扫描引导（复刻现有空状态视觉：标题 + 主按钮「扫描游戏文件夹」→ `bridge.scanFolder()`）。

## 5. 数据来源与计算（零后端改动）

- 数据源：`App.data.games`（30s 轮询 + UISync `applyGamesDelta` 增量），与列表同源，不新增桥方法、不新增持久化字段、不含 `date_added`。
- 继续游玩、统计、chips 均为前端派生计算。
- 渲染时机：进入主页时渲染；主页处于显示状态时，数据变化（轮询/增量/全量）同步刷新。
- 列表的筛选/搜索状态与主页互不影响：从主页进入「全部作品」时保持原有筛选与搜索。

## 6. 状态与边界

| 场景 | 行为 |
|---|---|
| 空库（0 作品） | 扫描引导块（§4.5） |
| 有库、无游玩记录 | 继续游玩隐藏；统计照常 |
| 无封面 / 坏封面 | 现有渐变兜底 + 懒加载（继承） |
| 超长标题/收藏夹名 | 省略号 + tooltip（继承卡片/树规则） |
| 收藏夹多于 8 个 | 只展示前 8 个；全量在「全部作品」抽屉 |
| 运行中的游戏 | 出现在继续游玩中并带「运行中」角标（`last_played` 启动即更新，自然靠前） |
| 窄窗 900×620 | 卡片一行 3 张、统计与 chips 折行；无横向滚动 |
| 封面档位 large/small | 跟随档位，自动换行不溢出 |
| 深色主题 | 全部沿用现有 token，无新增配色 |

## 7. 交互与可访问性

- 卡片/右键菜单/详情：全部复用现有实现与键盘路径。
- 统计可点击项：`<button>` 语义 + `aria-label`；只读项为普通文本。
- chips：`<button>`，键盘可达；筛选切换后的焦点与高亮沿用现有导航行为。
- 头像为装饰元素（`aria-hidden`）。
- 动效沿用现有 token 与 `prefers-reduced-motion` 处理。

## 8. 复用点（实现参考，实施时核对）

- 视图切换与高亮：`app.ts` 导航绑定、`state.ts` 的 `nav` 状态、`.side-item.active`。
- 卡片与封面：`cards.ts`（`buildCard`/懒加载/运行角标）、`--card-w/h`（`applyCoverSize`）。
- 收藏夹跳转：`collections.ts` 的 `selectCollection`；fav 跳转沿用导航点击逻辑。
- 空状态样式与扫描：`layout.css` 的 `.empty .primary`、`bridge.scanFolder()`。
- 刷新链路：`renderAll()` 同层挂主页刷新（与 `updateNavInfo`/`updateCollectionsEntry` 一致）。
- 图标：主页 = house（现有素材）；「全部作品」= 新素材（待用户提供）。

## 9. 验收标准（草案）

1. 启动默认落在主页且侧栏首项高亮；点击「全部作品」回到列表，列表筛选/搜索状态不丢。
2. 继续游玩：按最近游玩倒序 6 款；玩一款游戏后顺序正确更新；运行中角标正确；点击详情、右键菜单可用；无记录时整块隐藏。
3. 统计四项数值与库一致；前两项跳转正确；总时长格式符合 §4.3 口径。
4. 收藏夹 chips 点击筛选正确、超 8 个截断、无收藏夹隐藏。
5. 空库显示引导且可触发扫描。
6. 900×620 / 1366×768 / 深色主题下无溢出、无重叠；封面档位切换不破版。
7. 未改后端/数据库/桥契约；`git` 变更仅限前端与文档。
