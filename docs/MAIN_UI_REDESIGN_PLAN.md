# KazariPlay 主界面改造计划书

> 状态：`draft / pending-implementation`。本计划是主界面改造的唯一依据；开工前需确认 §8 待定项。
> 日期：2026-10-09
> 设计标准：[design/main-ui-prototype.html](design/main-ui-prototype.html)（来自工作区 `KazariPlay_redesign/collection-nav-prototype.html` 的快照）。主界面视觉与交互一律以该原型为准。
> 前身文档：[UI_OPTIMIZATION_DISCUSSION.md](UI_OPTIMIZATION_DISCUSSION.md)（2026-10-07 全量评审草案）。与其冲突处，以原型为准，修订记录见 §6；其余条目继续有效，但不在本计划范围内。
> 范围：**仅游戏库主界面**。其他窗口与行为**保持原版不动**：详情抽屉、设置、编辑/添加表单、收藏夹管理抽屉、截图预览与菜单、重新定位、批量栏、进度面板、toast。
> 约束：基于原版代码增量改造；**不新增功能、不新增前端模块、不迁移构建/框架**；不对整体结构做大规模重构。

---

## 1. 目标与范围

### 1.1 目标

主界面视觉与交互对齐原型：

- 左侧图标侧栏（导航 + 收藏夹开关 + 底部功能按钮）
- 副标题栏：当前视图名与数量 + 搜索 + 批量/排序操作
- 固定尺寸游戏卡片：底部单行 = 游戏名（左）+ 数字评分（右）
- 半透明收藏夹浮层，覆盖在卡片区上方、不占布局；展开时卡片区有浅色遮罩，点击遮罩关闭浮层且不触发卡片
- 右下角刷新/添加两个圆形 FAB（沿用原版）

### 1.2 范围内组件

| # | 组件 | 现状（原版） | 目标（原型） |
|---|---|---|---|
| 1 | 标题栏 | 品牌 + 窗口按钮 | 保持原版（原型未含窗口按钮，不照搬） |
| 2 | 侧栏导航 | 文字按钮（全部作品/继续游玩/我的收藏/收藏夹树/新建/设置） | 图标列：主页/全部作品/我的最爱 + 收藏夹开关；底部：个人主页（占位）/主题/设置 |
| 3 | 副标题栏 | 搜索绝对居中 + 批量选择 + 排序 | 左：视图名+数量；中：搜索（静态 flex）；右：批量选择 + 排序（显示当前规则） |
| 4 | 卡片 meta | 开发商（左）+ 星星评分（右） | 游戏名（左，省略号）+ 数字评分（右） |
| 5 | 收藏夹面板 | 侧栏内树（占布局） | 半透明浮层覆盖卡片区，不占布局，从副标题栏底部开始 |
| 6 | 遮罩 | 无 | 展开浮层时卡片区浅白粉遮罩；点击关闭浮层、不触发卡片 |
| 7 | FAB | 刷新 + 添加 + 菜单 | 保持原版 |

### 1.3 明确不做

- 不做详情/设置/表单/截图/批量/重新定位的视觉改造（按原版）。
- 不做新功能：不加新数据字段、不加新桥方法、不加新模块。
- 不迁移 React/Vue/构建工具；不上 CSS 框架；不动 Python 后端与 C++ overlay。
- 不改 `main.py` 内联机制与 `_JS_MANIFEST` 结构（仅在有新文件时登记，本计划不新增文件）。

## 2. 设计标准（原型规格）

以下为原型关键值，实施时以原型文件为准；括号内为原版现有值，如冲突按原型。

| 项 | 规格 |
|---|---|
| 整体布局 | 主行两列：图标侧栏（72px）+ 主区；主区 = 副标题栏 + 卡片滚动区 |
| 侧栏按钮 | 46×44，圆角 14px；active = 粉渐变底 + 白图标；hover = 浅底 + 深粉 |
| 侧栏底部 | 个人主页（占位，禁用态）、主题切换（图标随亮暗切太阳/月亮）、设置 |
| 副标题栏 | 高约 78px；左侧「视图名 + N 部作品」；搜索 `flex:1; max-width:480px`；右侧按钮 |
| 搜索 | 不再绝对居中；与视图区/操作区同一行 flex；空态/过滤态数量显示「匹配数 / 总数」 |
| 排序按钮 | 显示当前规则（如「添加时间」+下拉，选项：添加时间/作品名称/评分优先） |
| 卡片 | 154×210 固定（与原版一致）；封面 179px + meta 31px；hover 上浮 5px |
| 卡片 meta | 单行：左游戏名（`text-overflow:ellipsis`，`title`+`aria-label` 全名）；右数字评分（一位小数，如 `4.0`，橙色） |
| 收藏夹浮层 | 宽 248px；`left:72px; top:副标题栏底部; bottom:0`；半透明 `rgba(255,251,250,.72)` + `backdrop-filter: blur(16px)`；暗色 `rgba(33,30,37,.76)` |
| 浮层内容 | 头部「收藏夹 + 新建 + 收起」；分组（状态/题材等）可折叠；行 = 名称 + 数量；点击筛选 |
| 遮罩 | `rgba(255,246,249,.55)`（暗色 `rgba(24,19,32,.5)`）；覆盖卡片区（副标题栏底部→主区底）；点击关闭浮层 |
| z-index | 遮罩 < 浮层 < 副标题栏 < 模态 overlay(100) < 菜单；实施时用显式值并在 CSS 注释说明 |
| 动效 | 浮层/遮罩 0.28s；卡片 hover 0.28s 弹跳；保留 `prefers-reduced-motion` 降级 |
| 亮暗主题 | 两套都要覆盖新组件；沿用现有 `--bg-panel/--border-soft/--grad-pink` 等 token |

## 4. 阶段划分

| 阶段 | 内容 | 验证 |
|---|---|---|
| 1 | 侧栏图标化 + 底部功能按钮 + 主题图标切换 | 导航切换/收藏夹树入口/GUI 冒烟 |
| 2 | 副标题栏：视图名与数量、搜索静态布局、排序显示当前规则 | 搜索/排序/空态文案 |
| 3 | 卡片 meta：游戏名 + 数字评分（含增量更新路径） | 无封面/长名/评分更新/窗口化滚动 |
| 4 | 收藏夹浮层 + 遮罩 + 开关与点击关闭 | 开合、点击遮罩不触发卡片、筛选联动 |
| 5 | 视觉回归：亮暗主题、900×620～1920×1080、DPI | 对照原型逐项核对 |

每阶段独立提交、独立可回退；阶段 1~4 完成后再进入回归。

## 5. 验收标准

- 与原型对照：布局、尺寸、颜色、层级、交互一致（逐项核对 §2 表格）。
- 交互清单：侧栏导航、视图标题与数量、搜索过滤（含「匹配/总数」）、排序切换、收藏夹浮层开合、遮罩点击关闭且不触发详情、FAB 刷新/添加、主题切换。
- 其他窗口回归：详情、设置、表单、收藏夹管理、批量、截图、重新定位逐项冒烟不受影响。
- `npm run build` + `npm run typecheck` + `python tests/verify_frontend.py` PASS；GUI 源码启动手动核对。
- 900×620 最小窗口无溢出、无遮挡；暗色主题无未适配组件。

## 6. 与既有评审草案的冲突修订（以原型为准）

| # | `UI_OPTIMIZATION_DISCUSSION.md` 原文 | 本计划修订 |
|---|---|---|
| 1 | 卡片增加「常显标题两行 + 开发商次行」 | 改为**单行：游戏名（左）+ 数字评分（右）**；开发商不再出现在卡片 |
| 2 | 未指定评分形式 | 采用**数字评分**（一位小数），不再使用星星 |
| 3 | 搜索与命令参与同一布局、不绝对居中 | 保留（与原型一致） |
| 4 | 未涉及收藏夹面板位置 | 采用**半透明浮层覆盖卡片区 + 遮罩**，不占布局 |
| 5 | 配色示例（`--text-sub:#74687f`、`--action-bg:#b82f62` 等） | 以原型 token 为准（`--ink`、`--muted` 等对应值）；对比度达标作为独立可选优化，不改变原型视觉 |
| 6 | 异步核验、模态焦点、真实结果反馈、性能等条目 | 不变、继续有效；不属主界面改造，不在本计划内实施 |
